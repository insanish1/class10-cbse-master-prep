# Class 10 CBSE Master Prep

A clean rebuild of the Class 10 CBSE/NCERT preparation platform.

## Subjects
- Mathematics
- Science
- Social Science
- English
- French
- Artificial Intelligence (417)

## Current foundation
- Responsive dashboard for desktop, tablet and mobile
- Subject and chapter/skill selection
- Timed exam and practice modes
- Board-length target counts and timers
- Question palette and navigation
- MCQ scoring and explanations
- Local attempt history and performance dashboard
- Structured question records with chapter, type, marks, competency-ready metadata

## Board framework targets
Maths 38/180 min · Science 39/180 min · Social Science 38/180 min · English 11/180 min · French 34/180 min · AI 417 21/120 min.

This project deliberately avoids an automatic workflow that rewrites the live application. Question-bank expansion will be validated before deployment. Current CBSE/NCERT curriculum, sample question papers and marking schemes should be checked for the relevant examination year.
